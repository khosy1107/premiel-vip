# 프리미엘네일 VIP 계약서 (premiel-vip)

로그인 없이 어느 기기에서나 여는 계약서 페이지입니다. 제출하면 Google Apps Script가 받아
스프레드시트 `프리미엘네일 회원권 계약 내역` > `계약내역` 시트에 한 줄을 추가하고,
서명이 들어간 계약서 PDF와 서명 이미지를 드라이브 `프리미엘네일 계약서` 폴더에 저장합니다.

## 파일
- `index.html` — 계약서 페이지 (GitHub Pages로 공개)
- `apps-script.gs` — 스프레드시트에 붙여넣을 저장 코드

## 1. Apps Script 설정 (사장님 구글 계정, 1회)
1. 스프레드시트 `프리미엘네일 회원권 계약 내역`을 엽니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 누릅니다.
3. 기본 `Code.gs` 내용을 모두 지우고 `apps-script.gs` 내용을 붙여넣은 뒤 저장합니다.
4. 편집기 위쪽 함수 목록에서 `authorize`를 고르고 **실행** → 권한 요청이 뜨면 허용합니다.
   ("확인되지 않은 앱" 경고가 나오면 **고급 → 이동**을 누르세요. 사장님이 직접 만든 코드라 괜찮습니다.)
5. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 2. 페이지에 URL 넣기
`index.html`에서 아래 줄의 `url`에 복사한 주소를 넣습니다.

```js
var API = { url: "", token: "premiel-vip-2026" };
```

## 3. 공개 주소
공개(Public) 저장소 `premiel-vip`에 `index.html`을 올리고
**Settings → Pages → Branch: main / (root) → Save** 하면
`https://khosy1107.github.io/premiel-vip/` 로 열립니다.

## 참고
- 페이지 코드는 공개되지만 고객 정보는 페이지에 남지 않고 사장님 시트·드라이브로만 저장됩니다.
- 토큰(`premiel-vip-2026`)은 누구나 페이지 소스에서 볼 수 있어, 장난 제출을 완전히 막지는 못합니다.
  이상한 줄이 생기면 시트에서 지우면 됩니다.
- 같은 계약서를 다시 보내도(네트워크 오류 후 "다시 저장") 계약ID로 확인해 한 번만 저장합니다.
- 약관이나 문구를 바꿀 때는 `index.html`을 수정해 다시 올리면 됩니다.
